# 🧠 Quizionary

**Quizionary** is a sleek and interactive single-page quiz web application built using **React**. Designed for an engaging learning experience, Quizionary challenges users with multiple-choice questions, tracks progress, gives real-time feedback, and features per-question timers and smooth animations for a polished look and feel.

---

## 🚀 Features

- ✅ Clean, minimalistic UI with responsive design with light/dark mode
- ✅ Multiple-choice quiz functionality  
- ✅ Per-question countdown timer (default: 15 seconds)  
- ✅ Score tracking and summary at the end  
- ✅ Achievements Section 
- ✅ Smooth fade-in animations between questions  
- ✅ Option to restart quiz anytime  

---

## 🛠️ Technologies Used

- [React](https://reactjs.org/)
- [Vite](https://vitejs.dev/)
- HTML5 + CSS3  
- JavaScript (ES6+)
